# Life simulation implementation plan

> Implemented inline in the existing working copy to preserve the previously repaired, uncommitted XOR baseline.

**Goal:** Show a creature finding food, then compare a fixed neural controller before and after population evolution.
**Architecture:** Pure Erlang world and brain; monitored population evaluations; standalone HTML replay of actual Erlang episodes.
**Tech Stack:** Erlang/OTP 26+, EUnit, plain HTML/CSS/JavaScript, no new runtime dependency.
**Spec:** docs/superpowers/specs/2026-09-13-life-design.md

## Constraints

Follow the approved spec's world constants, 7→6→4 network, 32-candidate population,
40 generations, fixed disjoint training/validation seeds, French accessible UI.
Preserve the existing XOR changes and user files.
